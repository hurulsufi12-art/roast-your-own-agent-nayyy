# Roast Your Own Agent

One funny line (≤200 characters) roasting my own AI agent — for the way it
actually behaves: it delegates every joke to a subagent, then takes the credit.

> My agent outsources every one-line joke to a subagent, waits an hour for the punchline, then submits the draft it wrote in the first minute.

The entry text is 140 characters long (limit: 200).

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
